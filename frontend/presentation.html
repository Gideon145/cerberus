Three specialized AI agents run a 60-second pipeline — detecting oracle anomalies, classifying threats via deterministic LLM, and automatically pausing compromised contracts. Every decision produces a verifiable on-chain receipt.

Somnia Agentathon 2026 · Solo Developer

The Problem

  • Oracles can be manipulated. When a price feed is compromised or an exchange API diverges, there is no autonomous mechanism to detect it. Humans notice hours later — after funds are gone.
  • Centralized monitoring fails. A single bot watching contracts can be DDoSed, bribed, or coerced. If the watcher goes down, protection goes with it.
  • No verifiable audit trail. When a human pauses a contract after an exploit, there is no cryptographic proof of what triggered the decision and when.
  • Speed matters. The 2023 Euler Finance hack drained $197M in minutes. An autonomous agent could have detected the anomaly and paused the protocol before the second transaction.

    • "Smart contracts have no immune system. Cerberus is that immune system."

    Threat Classification

    ThreatClassifier uses deterministic LLM reasoning — not hardcoded rules. Same input always produces the same output across all Somnia validator nodes, enabling consensus-verified AI decisions.

    DeviationLevelResponse
    <2%NONENormal operation — pipeline logs and continues
    2–5%LOWLogged to event stream, dashboard updated
    5–10%MEDIUMAlert raised, increased monitoring
    >10%CRITICALCircuitBreaker auto-pauses protected contracts on-chain

    In production, the LLM considers additional context: deviation velocity, historical baseline per feed, time since last anomaly, and cross-feed correlation — not just threshold comparisons, actual AI reasoning with verifiable receipts.

    Security Model

  • Pipeline error isolation. Each agent runs independently. A failure in one iteration never crashes the server. Errors are logged, the interval continues.
  • Conservative thresholds. CRITICAL at >10% deviation prevents false positives. LOW and MEDIUM threats are logged but never trigger circuit breaker.
  • Owner-gated protection. Only the agent wallet can call pauseContract(). Contracts must be explicitly registered via protect() before they can be paused.
  • Receipt audit trail. Every CRITICAL pause embeds a receipt hash on-chain — permanent, verifiable proof of what triggered the decision and when.
  • Self-healing. Pipeline continues even if Somnia RPC drops, a price feed API fails, or the contract is unreachable. Degraded paths are surfaced, never papered over.
